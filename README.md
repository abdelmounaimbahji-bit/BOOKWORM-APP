# BOOKWORM-APP

## Project Idea
BOOKWORM-APP is a web application that lets users search for books and view detailed information using the Open Library API.  
Users can see the book cover, title, author, publisher, and additional details like description and number of pages.

## Goal
The app helps users discover books easily and provides an attractive and interactive user interface.

## Technologies Used
- React
- JavaScript
- HTML & CSS
- Tailwind CSS (optional)
- Open Library API

## How to Use
1. Search for books using the search bar.
2. View the list of matching books.
3. Click on a book to see detailed information.
